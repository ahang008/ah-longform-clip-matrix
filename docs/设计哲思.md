# 长内容切片矩阵的设计哲思

第一版切片的问题很具体：每段视频都能播放，观众却要知道长片前面说过什么，才能理解这一段。文件切出来了，观点没有切完整。

## 核心判断

长视频是一条按拍摄顺序展开的线；短切片是一个人带着单个问题点进来时，能走完的最短理解路径。两者的顺序不一定相同。

所以，切片的基本单位不是分钟，也不是金句，而是**承担明确作用的语义块**：提出问题、给出判断、解释原因、提供证据、交代条件、给出做法或完成收束。一个块可以被不同切片复用，但它周围的依赖必须一起处理。

## 为什么叫矩阵

同一份长内容可以回答不同问题。以《如何吃上 AI 博主这碗饭》为例，原片里的“不到两万粉丝时接到五千元合作”“品牌不只看粉丝数”“品牌缺教程、案例、曝光或注册”分散在不同位置。把这三块按“结果、原因、合作判断”组合，才是一条能独立观看的切片。

另一条切片可以复用“品牌缺什么”这个块，但前面换成“平台为什么给创作者资源”，回答的就是另一类观众的问题。矩阵的价值来自**同一证据在不同问题里的不同作用**，不是把同一条视频换几个标题。

## 四条约束

1. **完整性优先于数量。** 少做一条，也不要让观众替视频补前提。
2. **重排不能改写事实。** 不能把个人经历剪成普遍保证，把有条件的判断剪成绝对判断，也不能把前后发生的两件事剪成因果关系。
3. **口播连接词也属于内容。** “所以”“第三”“这件事”都有依赖；重组后找不到所指，就要补入原话中的铺垫、换块或删去该句。
4. **源时间必须可追溯。** 每条记录原片区间和排列顺序，方便回听、修改、核对数字和品牌名。

## Skill 的分工

AI 负责拆块、寻找组合、检查语义依赖和组织切片方案。渲染工具负责按确定的时间区间拼接、检查时长与音画文件。人工最后判断真实听感、语气是否自然，以及商业表述能否公开使用。

这套方法的验收问题只有一个：**把任何一条单独发给没看过原片的人，他能不能说清这条到底讲了什么，为什么成立，接下来该怎么做？**
